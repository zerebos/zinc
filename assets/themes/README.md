# Bundled color schemes

The `ghostty/` folder of [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
(MIT, see LICENSE.txt), at commit 99d9701ba3cf4a06d24eea6ca4f25a64656b446b 2026-09-27. Each file is a scheme in Ghostty's theme format,
named as `theme = "<file name>"` refers to it. Refresh with `scripts/dev/update-themes.ps1`.
